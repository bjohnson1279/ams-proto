## 2026-08-25 - [Async Button Loading State & Event Context Loss in Vanilla JS]
**Learning:** When dealing with asynchronous UI updates (like fetch API calls) in vanilla Javascript using inline HTML `onclick` handlers, passing the `event` explicitly (`onclick="myFunction(event)"`) and securely resolving the button element via `event.target.closest('.btn')` is essential. This prevents context loss and correctly identifies the triggering parent button even when a nested child element (like an icon or span) is clicked. Without disabling the button and changing its text, users lack visual feedback during async operations, which frequently causes multi-click network spam.
**Action:** Always implement async loading states for trigger buttons (disable + update text) in vanilla JS, restoring them inside a `finally` block, and use `event.target.closest('selector')` to reliably access the component element within inline handlers.

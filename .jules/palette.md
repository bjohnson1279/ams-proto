## 2024-08-27 - [Async Visual Feedback for Inline Handlers]
**Learning:** In vanilla JS components with inline HTML handlers (e.g., `onclick="..."`), event listeners might not implicitly pass the event object. Additionally, targeting the correct element within a nested structure (e.g., when clicking an icon inside a button) requires defensive checking like `event.target.closest('.btn')`. It is also important to wrap async operations in a `try/finally` block to guarantee the original button state and text are restored, even if the request fails.
**Action:** When adding loading states to inline async actions, explicitly pass `event` from the HTML (`onclick="myFunction(event)"`), use `closest()` to target the interactable element safely, and handle the state restoration in a `finally` block to prevent the UI from getting stuck in a loading state.

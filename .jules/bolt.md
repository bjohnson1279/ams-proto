## 2025-02-18 - Optimized Array Lookups in Memory Repositories
**Learning:** In-memory mock repositories or data structures that store records as arrays often perform O(N) linear scans when querying by ID (e.g., `this.accounts.find` or `this.accounts.filter`). While harmless for small datasets, this becomes a bottleneck for repeated queries or bulk fetches (causing O(N*M) complexity).
**Action:** When implementing or optimizing in-memory data classes, pre-compute or maintain a parallel `Map` during initialization. This allows replacing O(N) array scans with O(1) Map lookups for individual ID queries, and reduces bulk fetches from O(N*M) to O(M).
